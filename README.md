# PDDBuilder Android

PDDBuilder — приложение для создания, упаковки и редактирования `.pdd` проектов на Android.

## Возможности

- Создание `.pdd` проекта
- Импорт и экспорт `.pdd`
- Распаковка `.pdd`
- Работа с `mod.json`
- Работа с `mod.js`
- Поддержка PNG-иконок
- Поддержка структуры модов
- Локальное хранение проектов
- Минималистичный интерфейс
- Поддержка Android APK
